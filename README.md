# TF2 Medi Gun для Garry's Mod

Лечебная пушка медика из Team Fortress 2: лечение союзников лучом, накопление
Убер-заряда и активация неуязвимости на 8 секунд.

## Установка

Скопируйте папку аддона в `garrysmod/addons/weapon_tf2_medigun` (или подпишитесь
на Workshop-версию). Оружие появится в spawnmenu: вкладка **Weapons → Team Fortress 2**.

## Управление

| Клавиша | Действие |
| --- | --- |
| ЛКМ (зажать) | Лечить цель под прицелом и накапливать Убер-заряд |
| ПКМ | Активировать Убер-заряд при 100 % |

## Что нужно знать

- Лечить можно игроков, NPC и NextBot в радиусе 350 юнитов и только при прямой видимости.
- Цель можно менять на ходу — достаточно навести прицел на другого союзника.
- Убер делает неуязвимым медика и его пациента (урон блокируется полностью).
- Скорость игрока с медиганом — 214/428; при смене оружия, смерти и удалении
  оружия возвращаются исходные значения.

## Содержимое

- `lua/weapons/weapon_tf2_medigun/shared.lua` — вся логика оружия (shared).
- `lua/autorun/client/cl_tf2_spawnmenu_icon.lua` — иконка категории в spawnmenu.
- `models/`, `materials/`, `particles/`, `sound/` — ассеты TF2 (Medi Gun + лучи/звуки).
